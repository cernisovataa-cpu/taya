Розрахунок зони покриття базової станції 

Курсова робота з розрахунку енергетичного бюджету радіолінії та планування стільникових мереж.

 Опис
Програма мовою Python для автоматизованого розрахунку максимального радіуса покриття базової станції стільникового зв'язку на основі математичної моделі Окумура-Хата. Дозволяє аналізувати затухання радіосигналу залежно від відстані та морфології середовища.

Функції
* **Гнучкість розрахунків:** Обчислення втрат радіосигналу для 3 типів місцевості (місто, передмістя, відкритий простір/село).
* **Ітераційний алгоритм:** Пошук максимального радіуса впевненого прийому (до перетину з межею чутливості приймача).
* **Soft Validation:** Вбудована система перевірки вхідних інженерних параметрів із попередженнями про критичні або аномальні значення.
* **Візуалізація:** Побудова наочних лінійних графіків затухання сигналу від відстані за допомогою `matplotlib`.
* **Звітність:** Автоматичний експорт підсумкового звіту з результатами у форматі TXT (`coverage_report.txt`).
