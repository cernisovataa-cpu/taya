Аналізатор ефективності частотного спектру
Навчальний/дослідницький додаток на Python (Tkinter + Matplotlib) для генерації багаточастотних сигналів та аналізу їх спектральних характеристик.

Функціонал:

Генерація сигналів: Створення суміші синусоїдальних сигналів із заданою кількістю частот та накладанням білого шуму.

Математичний аналіз (FFT): Розрахунок швидкого перетворення Фур'є.

Обчислення метрик: Автоматичний розрахунок спектральної ефективності, ширини смуги (за порогом 10%) та PAPR (пік-фактора).

Візуалізація: Побудова графіка нормованої спектральної потужності з відображенням порогів.

Збереження параметрів: Можливість експорту та імпорту введених вхідних налаштувань (n, час, частота дискретизації, шум) у текстовий файл.

Автоматичне встановлення необхідних бібліотек (numpy, matplotlib) при першому запуску.
